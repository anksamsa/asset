Running the live search above
  1. Keep bpsm-navigator.html, bpsm_search.py, and bpsm_server.py in the same folder.
  2. pip install flask requests beautifulsoup4
  3. Run python bpsm_server.py in a terminal.
  4. Open http://127.0.0.1:5000/ in your browser — not this file directly. The search box only works when the page is served from that local address, since it talks to the local server, not bpsm.bihar.gov.in, directly from the browser.

That indirection exists because browsers block cross-origin requests from a plain HTML file straight to bpsm.bihar.gov.in (CORS) — the local server does that part instead and just hands the results back to the page.
